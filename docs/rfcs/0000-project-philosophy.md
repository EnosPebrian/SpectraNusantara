# RFC-0000

# SpectraNusantara Philosophy

Status: Accepted

Author: Enos Pebrian

## Vision

Build an open-source exploration geology platform that combines:

- Remote sensing
- Field spectroscopy
- Geological interpretation
- Exploration workflows

inside one desktop application.

The software should become the open alternative to
ENVI + TSG + GIS workflows.

---

## Principles

### Geologist First

Every feature must solve a geological problem.

---

### Open

No vendor lock-in.

Support open formats whenever possible.

---

### Modular

Sensors are plugins.

Algorithms are plugins.

Libraries are plugins.

---

### Reproducible

Every processing step is recorded.

---

### Extensible

The software should still be maintainable after ten years.
